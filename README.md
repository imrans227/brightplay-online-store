# BrightPlay online store

A responsive static storefront for BrightPlay, built for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — responsive black-and-gold styling
- `script.js` — sample product catalogue, search, filters, sorting and WhatsApp order flow

## Before publishing
1. Open `script.js` and replace the sample products with your real products, prices and image URLs.
2. Check product photos and prices carefully. The current catalogue is demonstration content only.
3. Confirm the WhatsApp number and social profile URLs in `index.html` and `script.js`.

## Publish with GitHub Pages
1. Open your repository: https://github.com/imrans227/brightplay-online-store
2. Select **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` (upload the files, not the ZIP).
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait for GitHub Pages to publish. Your expected site address is:
   https://imrans227.github.io/brightplay-online-store/

## Current functionality and limitations
- Product search, category filters and price sorting.
- “Add to order” opens WhatsApp with a prepared order message.
- WhatsApp contact button and Instagram/TikTok profile links.
- Responsive layout for mobile and desktop.
- This is a front-end demo. It does not process payments, store orders, manage stock, create customer accounts, or synchronize social accounts/products automatically.
- Product prices and catalogue items are sample placeholders and must be replaced before accepting real orders.
